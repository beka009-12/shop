Dock-поиск — как он должен выглядеть?

Три варианта размещения поиска внизу по центру (desktop). Слева — боковая навигация 64px, справа — весь контент.

Поиск товаров... ⌘K

A — Постоянная pill снизу по центру

Всегда видна, плавает над контентом. Нажатие фокусирует инпут. Shortcut ⌘K. Убирается из левого сайдбара.

нажми чтобы открыть поиск

B — Кнопка-иконка, раскрывается в полную строку

В закрытом виде — компактная кнопка. При нажатии разворачивается в full-width строку поиска (spotlight-стиль). Меньше шума на экране.

Поиск... ESC

C — Spotlight / CMD+K модальный оверлей

Поиск открывается по ⌘K или кнопке, накрывает экран затемнённым оверлеем. Результаты прямо в этом окне. Как Linear/Raycast.
